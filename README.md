# satesoft frontend

Vite React frontend for SATESOFT.

## Run

```bash
PATH=/home/likycoder/node-v22.14.0-linux-x64/bin:$PATH npm run dev -- --host 0.0.0.0
```

The dev server runs on `http://localhost:3001`.

## Build

```bash
PATH=/home/likycoder/node-v22.14.0-linux-x64/bin:$PATH npm run build
```
